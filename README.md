# Employee Data Analysis Using Python

## Project Overview

This project analyzes employee data using Python to discover useful patterns and insights about employees, salaries, experience, departments, gender, and cities.

The project includes data inspection, data cleaning, statistical analysis, and data visualization.

## Tools & Technologies

* Python
* NumPy
* pandas
* Matplotlib
* Google Colab

## Analysis Performed

* Dataset inspection and exploration
* Checking data types and missing values
* Removing duplicate records
* Handling missing values
* Statistical analysis of numerical data
* Analysis of categorical data
* Salary and age distribution
* Employee distribution by department, gender, and city
* Average salary by department
* Experience vs. salary analysis
* Data visualization using Matplotlib

## Key Insights

* The dataset contains **100 employees** and **12 columns**.
* After cleaning, there are no missing values or duplicate rows.
* The average employee age is **40.89 years**.
* The average salary is approximately **17,970.30**.
* The average work experience is **10.46 years**.
* **Marketing** has the highest number of employees.
* Female employees represent **58%** of the dataset, while male employees represent **42%**.
* **Mansoura** has the highest number of employees among the listed cities.
* Employee salaries range from **5,384 to 29,323**.
* Employee experience ranges from **0 to 20 years**.
* The project also explores the relationship between experience and salary.
